What Open DJ is

Open DJ is a native window onto a local engine process. The window ships in this app. The engine does not: it runs from a source checkout on this machine and serves the whole user interface over HTTP. No engine means no interface, which is what you are looking at.

Bundling the engine inside this app is not implemented yet. See PARITY-TODO.md.

Start the engine

  1. Open Terminal.
  2. Install uv if you do not have it (one binary, no Python required first): 
    curl -LsSf https://astral.sh/uv/install.sh | sh
  3. Change into the music-dj-tools checkout you were given.
  4. Start the engine, pointing it at an absolute data directory: 
    (resolving)
  5. Leave that Terminal window open. This window retries on its own, or press Check now.
What exactly was tested

A cross origin fetch in no-cors mode against (unknown). The browser sandbox will not let this page read a cross origin response body, so this test proves reachability only: that something accepted a TCP connection and answered HTTP at that address. It does not prove the responder is the Open DJ engine, and it does not read the engine's health payload. Once the window navigates to the engine origin, every later request is same origin and the real interface reports its own status.
