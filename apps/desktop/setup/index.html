What Open DJ is

Open DJ is a native window onto a local engine process, and both ship inside this app: the engine, its Python runtime and the whole user interface live in the app bundle. The app starts the engine itself, on a free local port, before it opens a window. No source checkout is needed.

Which makes this screen specific rather than generic. A bundled engine that fails to start raises a system error dialog and the app quits; it never reaches here. Reaching here means this window was pointed at an engine address by hand, through the OPENDJ_ENGINE_ORIGIN environment variable or a ?engine= query, and nothing is answering at that address.

What to do

  1. To use the engine that ships inside this app: quit it, unset OPENDJ_ENGINE_ORIGIN, and open the app again from Finder.

What exactly was tested

A cross origin fetch in no-cors mode against (unknown). The browser sandbox will not let this page read a cross origin response body, so this test proves reachability only: that something accepted a TCP connection and answered HTTP at that address. It does not prove the responder is the Open DJ engine, and it does not read the engine's health payload. Once the window navigates to the engine origin, every later request is same origin and the real interface reports its own status.
