Star rating: five `.rb-star` glyphs, `.filled` for set stars, `.preview` for the hover candidate, `--rb-star-size` for narrow cells. Inside `.perf-root`.

```html
<div title="Rating: 3 of 5">
  <span class="rb-star filled">★</span><span class="rb-star filled">★</span><span class="rb-star filled">★</span>
  <span class="rb-star">★</span><span class="rb-star">★</span>
</div>
```

The container's `title` states "N of 5". Unrated shows five empty stars, never a dash.
