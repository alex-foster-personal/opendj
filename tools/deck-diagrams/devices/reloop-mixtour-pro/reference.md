# Reloop MIXTOUR PRO: exhaustive control reference

This reference accompanies the retained `midi.json` controller mapping. The manual image and its diagram renderer are withheld from this public copy pending redistribution permission; diagram regeneration is unavailable here.
The interactive diagram is unavailable in this public copy. Channel key: N deck transport+mixer,
P deck pads/mode, E deck FX unit, G global; deck 1 shown, deck d adds d-1 to N/P/E.

## Pad modes

| Select | Mode | Pads do | SHIFT + pad |
|---|---|---|---|
| MODE + pad 1 | HOT CUE | Pads trigger the 8 cue points; each pad lights in that cue's color. | Deletes the cue point on that pad. [IM] |
| MODE + pad 2 | BOUNCE LOOP | Momentary loop roll: the loop runs while the pad is held, length varies per pad. | Not documented in [IM]; SHIFT+pad still sends its own note (P 1C..23). [IM] |
| MODE + pad 3 | PITCH CUE | Pads set the musical key of the track (pitch play from a cue point). | Switches between cue points used as the pitch-play source. [IM] |
| MODE + pad 4 | INSTANT FX | Each pad is an instant effect, active while pressed. | Not documented in [IM]; SHIFT+pad still sends its own note (P 1C..23). [IM] |
| MODE + pad 5 | AUTO LOOP | Each pad is a fixed loop length; press to start the loop, press again to release it. | Not documented in [IM]; SHIFT+pad still sends its own note (P 1C..23). [IM] |
| MODE + pad 6 | SAMPLER | Pads trigger the corresponding sample in the sample bank. | Not documented in [IM]; SHIFT+pad still sends its own note (P 1C..23). [IM] |
| MODE + pad 7 | SAVED LOOPS | A bank of up to 8 saved loops per track for instant recall. | Triggers the saved loop instantly (manual wording). [IM] |
| MODE + pad 8 | NEURAL MIX | Pads control the Neural Mix stem elements (vocals, harmonic, drums per deck). | Not documented in [IM]; SHIFT+pad still sends its own note (P 1C..23). [IM] |

## LED coding

- RGB pads: value = 64*full + 16*R + 4*G + B, R/G/B in 0..3 (0/33/66/100%); 0..63 dimmed 25%, 64..127 full [MM].
- Transport bi-LEDs: 0x00 off; 0x01 red, dimmed 25%; 0x02 blue, dimmed 25%; 0x03 red + blue (purple), dimmed 25%; 0x7D red, full; 0x7E blue, full; 0x7F red + blue (purple), full [MM][HW].
- NEURAL MIX / HEADPHONE CUE: OFF 00, DIM 01, ON 7F. MODE / SPLIT: DIM 00, ON 7F. FX ON: OFF 00, DIM 01, ON 02, FLASH 7F. DECK 3/4 LED: N note 08, 00 / 7F. VU: N CC 1F 00..06 [MM].

## Hardware without MIDI

- 11a FILTER ON/OFF LED: Lit whenever the FILTER knob is off center, dark at 12 o'clock. Hardware-driven, no MIDI address [MM].
- 26 HEADPHONES OUT: 3.5 mm TRS stereo headphone jack on the front edge; 4 +/- 1 dBu at 32 ohm [IM].
- 27 MASTER OUT (RCA): Unbalanced RCA L/R main output on the rear, 18 +/- 1 dBu [IM]. Follows the MONO/STEREO switch.
- 28 USB-C PORT (device / charging icon): USB-C with the tablet-and-bolt icon: the playback device (iPad, iPhone, Android, Mac, PC) connects here and is charged through it, up to 45 W power delivery [IM]. Also the bus-power input when no supply is attached [IM].
- 29 USB-C PORT (20 W supply icon): USB-C with the 20 W plug icon: power supply input, 5-20 V, minimum 20 W [IM]. The manual's prose numbers these two ports inconsistently against its own designation list; the icons are the reliable guide.
- 30 POWER: Power on / off push button on the rear [IM].
- 31 KENSINGTON LOCK: Security slot on the left side panel [IM].
