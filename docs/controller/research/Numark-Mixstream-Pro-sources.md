## WebMIDI device name

The USB port enumerates as "Mixstream Pro". `nameMatch: 'Mixstream\\s*Pro(?!\\s*(?:\\+|Plus|Go))'` (case-insensitive) misses Mixstream Pro+, Mixstream Pro Go, and Mixtrack controllers. No unit was plugged in.

## Runtime map

`apps/webui/frontend/src/lib/rb/midi/maps/numark-mixstream-pro.ts` exports `NUMARK_MIXSTREAM_PRO_MAP`: hints only, no bindings. Deck transport on channels 3 / 4, channel strips on 1 / 2, FX on 5 / 6, globals on 16. VU meters CC 32 / 33 on channel 16 when enabled in the script.

Registered for the practice route only (`PRACTICE_DEVICE_MAPS`), not in `DEVICE_MAP_REGISTRY`.
