## Practice replica

`tools/deck-diagrams/devices/sc-live-4/panel.json` (128 controls) and `panel.reference.json` (the measured trace, `"measured": true`) are generated by `tools/deck-diagrams/scripts/build_sc_live_4_panel.py`; the route is `/practice/sc-live-4`.

Because no MIDI list exists, `apps/webui/frontend/src/lib/rb/midi/maps/sc-live-4.ts` (`SC_LIVE_4_MAP`) binds nothing: every panel control carries a placeholder wire on channel 16 that the map lists as a hint, so the replica renders each control inert with the PARITY-TODO tooltip. The map is registered in `PRACTICE_DEVICE_MAPS` only, never in `DEVICE_MAP_REGISTRY`, so a real SC LIVE 4 port is never matched to placeholder wires. The scaffolder (`new_panel.py`) is not used for this device: it emits one control per map binding, and there are none.
